# CyberCare — Pacote corrigido (português brasileiro)

1. Abra `prototipo/index.html` no navegador. Clique em **Computador** e **Celular** e navegue nas seis telas.
2. A identidade visual é baseada no pôster em `referencias/poster_original.jpg`, não em imagens genéricas.
3. Leia `AGENTS.md`, `PROMPT_CODEX.md` e `DOCUMENTACAO_TECNICA.pdf`.
4. Abra esta pasta no VS Code e peça ao Codex para implementar as telas responsivas e a API.
5. O protótipo é uma referência visual: não coleta dados nem representa um sistema pronto.

**Stack:** React web + Vite + TypeScript + Tailwind; FastAPI; Neon PostgreSQL; Railway.
**Prazo:** vídeo virtual até 18/10/2026, com estudantes e legendas.
